# Portfólio Pessoal
[![en](https://img.shields.io/badge/language-en-blue)](/README.md)
[![pt-br](https://img.shields.io/badge/language-pt--br-green)](/README.pt-br.md)

Um portfólio pessoal desenvolvido com React e TypeScript para apresentar meus projetos, habilidades técnicas e minha trajetória como desenvolvedor de software.

O site possui uma interface inspirada em terminais, combinando a estética da linha de comando com uma maneira simples de explorar minha trajetória e meus projetos.

## Demonstração
Visite meu portfólio! [Clique aqui](https://vianavitor-portfolio.vercel.app/)

## Funcionalidades

- **Sobre Mim:** Conheça minha trajetória, habilidades e interesses no desenvolvimento de software.
- **Meus Projetos:** Explore meus projetos, suas descrições, tecnologias utilizadas e links relevantes.
- **Detalhes dos Projetos:** Confira informações adicionais sobre cada projeto por meio de um painel interativo.
- **Interface Inspirada em Terminal:** Navegue pelo portfólio por meio de uma experiência inspirada em terminais.
- **Design Responsivo:** Acesse o portfólio em computadores e dispositivos móveis.
- **Navegação Simplificada:** Alterne entre as páginas Sobre Mim e Meus Projetos sem precisar utilizar comandos do terminal.

## SEO

O site inclui títulos e descrições localizados, metadados para compartilhamento em redes sociais, dados estruturados e uma URL canônica.

## Como Começar

### Pré-requisitos

Certifique-se de ter o [Node.js](https://nodejs.org/) e o npm instalados.

### Instalação

1. Clone o repositório:

   ```bash
   git clone https://github.com/vianavitor-dev/portfolio-website
   ```

2. Acesse o diretório da aplicação:

   ```bash
   cd portfolio-website/portfolio
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

5. Abra a URL local exibida no terminal para visualizar o portfólio.

## Estrutura do Projeto

O projeto é organizado em componentes React reutilizáveis e componentes de página separados, facilitando a manutenção e a expansão da aplicação.

```text
src/
├── components/    # Componentes reutilizáveis da interface
├── pages/         # Páginas do portfólio
├── hooks/         # Hooks personalizados do React
├── common/        # Tipos e interfaces compartilhados
├── App.tsx        # Componente principal da aplicação
├── App.css        # Estilos da aplicação
├── i18n.tsx       # Configuração da biblioteca de tradução
└── main.tsx       # Ponto de entrada da aplicação
```
