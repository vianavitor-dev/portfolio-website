# Personal Portfolio

[![pt-br](https://img.shields.io/badge/language-pt--br-green)](/README.pt-br.md)


A personal portfolio built with React and TypeScript to showcase my projects, technical skills, and journey as a software developer.

The website features a terminal-inspired interface, combining a command-line aesthetic with a simple way to explore my background and projects.

## Live Demo
Visit my portfolio! [Click here](https://vianavitor-portfolio.vercel.app/)

## Features

- **About Me:** Learn more about my background, skills, and interests in software development.
- **My Projects:** Browse my projects and explore their descriptions, technologies, and relevant links.
- **Project Details:** View additional information about each project through an interactive details panel.
- **Terminal-Inspired Interface:** Navigate the portfolio using a terminal-style experience.
- **Responsive Design:** Access the portfolio across desktop and mobile devices.
- **Simple Navigation:** Switch between the About Me and My Projects pages without relying on terminal commands.

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/vianavitor-dev/portfolio-website
   ```

2. Navigate to the application directory:

   ```bash
   cd portfolio-website/portfolio
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal to view the portfolio.

## Project Structure

The project is organized into reusable React components and separate page components to keep the code maintainable and easy to extend.

```text
src/
├── components/    # Reusable UI components
├── pages/         # Portfolio pages
├── hooks/         # Custom React hooks
├── common/        # Shared types and interfaces
├── App.tsx        # Main application component
├── App.css        # Application styles
├── i18n.tsx       # Translation library setup
└── main.tsx       # Application entry point
```
